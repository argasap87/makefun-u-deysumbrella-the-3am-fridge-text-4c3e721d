A [make.fun](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) entry for **The 3AM Fridge Text**: the one line a smart fridge would text its owner at 3am.

`main.ts` (pure Node.js, no dependencies) writes the line to `/output/entry.txt`, guarded to the bounty gate: 1–140 characters, a single line, no newline, no invisible/control characters, non-blank only, and verified byte-identical on read-back.

```sh
node main.ts
cat /output/entry.txt
```

## The line

> I heard you laughing at the microwave's beeps — does he keep you warm at night too?

The hook: a jealous fridge. It is cold, the microwave is warm, and at 3am it has finally decided to say so.
